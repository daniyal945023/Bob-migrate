## Breaking Changes

| Area | Change | Impact |
|---|---|---|
| **Pydantic model config** | `class Config` removed; replaced with `model_config = ConfigDict(...)` | Internal — no public API change |
| **Serialization** | `.dict()` → `.model_dump()`, `.copy()` → `.model_copy()` | Callers using old method names directly will break |
| **Parsing** | `.parse_obj()` → `.model_validate()`, `.parse_raw()` → `.model_validate_json()` | Callers using legacy class methods directly will break |
| **Web framework** | `Flask` → `FastAPI` | Server entrypoint changes; WSGI → ASGI. Deploy with `uvicorn` instead of `flask run` |
| **Route paths** | `<int:user_id>` → `{user_id}` | Internal route syntax change; no external API path change |
| **Error handling** | `return jsonify(...), 4xx` → `raise HTTPException(...)` | Internal only |

> **Risk Tier: 🟢 LOW** — All public HTTP routes, payloads, and status codes are unchanged. Breaking changes are confined to internal Python method names on model classes.
